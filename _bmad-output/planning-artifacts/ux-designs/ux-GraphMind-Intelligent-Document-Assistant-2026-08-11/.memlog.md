- (decision) Source: prd.md + addendum.md from prd-GraphMind-Intelligent-Document-Assistant-2026-08-11 (confirmed sole sources)
- (decision) Platform: web app only
- (decision) Visual inspiration: follow Sirma's existing site color palette; NotebookLM for interaction/layout ideas
- (decision) IA: Login page, Registration page, then authenticated shell with left sidebar containing: User Settings, Documents, Chat, Graph Preview, Exit
- (decision) Documents page: documents listed with preview, metadata, delete; sortable and filterable by type and date; Upload button opens a modal with upload option
- (decision) Chat page: chat visualization window, small robot figure above the typing field; outside the chat window a search bar to find and add documents to the session's scope; selected document names shown on the right of the chat window; a Select All docs option exists
- (decision) Palette direction from Sirma site research: deep blue primary/brand, white-dominant background, light gray secondary sections, vibrant blue CTAs/links, dark charcoal text, clean sans-serif, subtle rounded corners, generous whitespace, professional-yet-approachable tone

- (decision) User Settings page holds all account-related settings: profile info, password change, theme, account deletion
- (decision) Graph Preview is read-only for v1 (no interactive editing/querying)
- (decision) Dark mode is in scope for v1
- (decision) Key flow (Maria): logs in -> Documents page -> Upload button opens modal -> uploads 3 docs -> modal closes -> docs appear with Uploaded status -> clicking a doc shows metadata once extracted, with a trashcan delete + confirmation -> sorts documents by most recent -> visits Graph Preview to see the diagram -> in Chat selects 'all docs' -> asks a question -> receives an answer with citations showing which chapter of which document they come from.
